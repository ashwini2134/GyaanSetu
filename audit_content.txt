TITLE: What is Python?

--- Section 1: What is Programming? ---
[Explanation: What Does It Mean to Program?]
**Programming** is the art of giving instructions to a computer so it can perform tasks automatically. Instead of clicking buttons in an app, you write the instructions yourself. The computer follows them step by step, exactly as written.
Computers are very fast but also very literal — they do exactly what you tell them
- Programming lets you automate repetitive tasks
- Programs are written in a **programming language** like Python, which both humans and computers can understand
- Every program is just a sequence of instructions stored in a text file
[Analogy: Think of a Program as a Cooking Recipe]
A recipe lists ingredients and steps: chop onions, boil water, cook for 10 minutes. A program does the same thing — it lists steps like 'store this value,' 'add these two numbers,' 'print the result.' The computer follows the recipe just like you follow cooking instructions.
[Think Of]
Recipe: Ingredients + Steps → Dish
[Explanation: Programming Languages]
There are hundreds of programming languages, each designed for different purposes. Python is special because it is designed to be easy to read and write.
Python's syntax (the rules for writing code) is similar to English
- You can write simple programs with just a few lines of code
- Python hides complex details so you can focus on solving problems
[Code Example: Your First Program — Hello World]
print("Hello, World!")

--- Section 2: Why Python? ---
[Explanation: Why Python is Perfect for Beginners]
Python was created by Guido van Rossum in 1991 with a clear philosophy: make programming easy and fun. Today it is used by beginners and professionals alike.
Easy to read — Python code looks almost like plain English
- No complicated symbols or punctuation — clean and minimal
- Huge community — millions of tutorials and libraries available for free
- Runs everywhere — Windows, Mac, Linux, even on small devices
[Explanation: Real-World Applications of Python]
Python is not just for learning — it powers some of the most important technology in the world.
**Web Development** — Instagram, Pinterest, and Spotify use Python for their backends
- **Data Science** — Python is the #1 language for analyzing data and building charts
- **Artificial Intelligence** — Most AI and machine learning libraries are written in Python
- **Automation** — Python can automate boring tasks like renaming files or sending emails
[Analogy: Think of Python as a Swiss Army Knife]
A Swiss Army knife has many tools — blade, scissors, screwdriver — all in one device. Python is the same: you can build websites, analyze data, make games, or automate tasks, all with the same language.
[Think Of]
Swiss Army Knife: One tool, many uses

--- Section 3: Getting Started ---
[Explanation: Installing Python]
Before you can write Python programs, you need to install Python on your computer. It's free and takes just a few minutes.
Go to python.org and download the latest version
- Run the installer and check 'Add Python to PATH'
- After installation, open Terminal (Mac/Linux) or Command Prompt (Windows)
- Type python --version to verify it installed correctly
[Think Of]
Setting Up Your Kitchen: Gather tools before you cook
[Explanation: Python Shell (Interactive Mode)]
The **Python shell** (also called REPL) lets you type Python commands one at a time and see results immediately.
Type python in your terminal to start the shell
- You'll see >>> prompt — Python is waiting for your command
- Type print("Hello") and press Enter — Python runs it instantly
- Type exit() to leave the shell
[Explanation: Running .py Files]
For real programs, you save your code in a file with a .py extension and run the entire file at once.
Create a new file called hello.py
- Write your Python code in the file using any text editor
- Open terminal, navigate to the folder containing the file
- Type python hello.py and press Enter — Python runs every line in order
[Code Example: Interactive Shell vs File: Same Code, Same Result]
# In the shell:
>>> print("Hello, World!")
Hello, World!

# In a .py file:
print("Hello, World!")

# Run: python myfile.py
# Output: Hello, World!
[Explanation: Python is Interpreted]
Python is an **interpreted language**, which means it runs your code line by line without needing a separate compilation step.
No compile step — write code and run it immediately
- If Python finds an error on line 5, it stops there and shows the error message
- This makes Python great for beginners — you get instant feedback
- You can test small pieces of code in the shell without creating files

TITLE: Variables & Data Types

--- Section 1: Variables ---
[Explanation: What is a Variable?]
A **variable** is a named container that stores a value. Think of it like a labeled box where you can put information. You create a variable with the `=` sign.
Variables store values like numbers, text, or true/false
- Use the = sign to assign a value: name = "Lakshanya"
- Once assigned, use the variable name anywhere to access the value
- Variables can be updated — old value is replaced
[Analogy: A Variable is a Labeled Jar]
Imagine jars with labels. One jar labeled 'sugar' contains sugar. Another labeled 'flour' contains flour. You look at the label to know what's inside. In Python, the label is the variable name and the contents is the value.
[Think Of]
Labeled Storage Box: Each box has a label and holds one item
[Explanation: Naming Rules]
Variable names must follow clear rules.
Start with a letter or underscore (_), not a number
- Use only letters, numbers, and underscores
- Case-sensitive: myVar and myvar are different
- Cannot use Python keywords like if, else, while, for, print
[Code Example: Creating Variables]
name = "Lakshanya"
age = 20
height = 5.6

print(name)

- Be careful: int("hello") causes an error because "hello" is not a number

--- Section 1: Arithmetic Operators ---
[Explanation: Math in Python]
Python can do all the math you learned in school. Arithmetic operators let you add, subtract, multiply, divide, and perform advanced operations.

- // floor division — divides and rounds down

[Explanation: PEMDAS — Order of Operations]
Python follows standard math rules: Parentheses, Exponents, Multiplication/Division, Addition/Subtraction.
Parentheses () have the highest priority
- Exponents ** come next
- Multiplication *, Division /, Floor Division //, Modulo % are next
- Addition + and Subtraction - are last

TITLE: Conditional Statements

--- Section 1: if Statements ---
[Explanation: Making Decisions with if]
The `if` statement lets you run code only when a condition is True. If False, the code is skipped.
Write if followed by a condition and a colon
- The code to run goes on the next line, indented 4 spaces
- Python uses indentation to show what code belongs to the if
- If True, the indented block runs; if False, it is skipped
[Analogy: if is Like a Traffic Light]
Green light (True) → you go. Red light (False) → you stop. The if statement checks the condition and decides whether to run the code or skip it.
[Think Of]
Traffic Light: Green → GO, Red → STOP. The condition decides which path to take.
[Code Example: Basic if Statement]
age = 18
if age >= 18:
    print("You are an adult")
    print("You can vote!")

--- Section 2: if-else & elif ---
[Explanation: Two Paths with if-else]
When you need to choose between two options, use if-else. One block runs if True, another if False.
if condition: — runs when True
- else: — runs when False
- Only ONE of the two blocks runs, never both
[Code Example: if-else in Action]
age = 16
if age >= 18:
    print("You can vote")
else:
    print("Too young to vote")
[Explanation: Multiple Conditions with elif]
When you have more than two possibilities, use elif. You can chain as many as needed.
if checks the first condition
- elif checks the next (if previous was False)
- else runs only if ALL conditions were False
[Explanation: Truthy and Falsy Values]
Some values are treated as True (truthy) and others as False (falsy) in conditions.
Falsy: None, 0, 0.0, "" (empty string), [] (empty list)
- Truthy: everything else — non-zero numbers, non-empty strings
- Lets you write concise conditions like if name:

--- Section 1: Loop Basics ---
[Explanation: What is a Loop?]
A **loop** repeats a block of code multiple times. Instead of writing the same code 10 times, you write it once inside a loop.
Loops eliminate repetitive code
- You control how many times the loop runs
- Each repetition is called an iteration
[Analogy: A Loop is Like a Washing Machine Cycle]
You load clothes, set the timer, and the machine repeats the cycle until time runs out. A for loop processes each item in a list automatically.

Washing Machine Cycle: The machine runs through each step automatically for every item

TITLE: While Loops

--- Section 1: while Loop ---
[Explanation: The while Loop]
A `while` loop keeps running as long as its condition is True. It checks the condition BEFORE each iteration.
while condition: — checks before each run
- If True, the body runs, then checks again
- If False, the loop stops
[Analogy: while is Like Checking Your Phone]
While waiting for a friend: check for messages. No message → wait. Message arrives → stop. The while loop checks a condition and keeps going until it changes.
[Think Of]
Checking Your Phone: Keep checking until there are no more notifications
[Code Example: Basic while Loop]
count = 1
while count <= 5:
    print(f"Count: {count}")
    count = count + 1
print("Done!")
[Explanation: Avoiding Infinite Loops]
An **infinite loop** runs forever because the condition never becomes False.
Always update the counter variable inside the loop
- Make sure the condition will eventually become False
- Use break to exit early if needed
- Press Ctrl+C to stop a running program

--- Section 2: break & continue ---
[Explanation: Controlling Loop Flow]
Sometimes you need to exit early or skip an iteration. break and continue give you this control.
break — exits the loop immediately
- continue — skips to the next iteration
- break is useful for 'found it!' scenarios
- continue is useful for 'skip this one' scenarios
[Code Example: break — Exit Early]
for num in range(1, 10):
    if num == 5:
        print("Found 5! Stopping...")
        break
    print(f"Checking: {num}")
[Explanation: while vs for]
Choose the right loop for the right job.
Use for when you know the count or have a list
- Use while when waiting for a condition to change
- for loops are safer (no infinite loops)

TITLE: Lists

--- Section 1: List Basics ---
[Explanation: What is a List?]
A **list** is an ordered collection of items enclosed in square brackets []. You can store any type of data.
Create: fruits = ["apple", "banana", "cherry"]
- Items are separated by commas
- Lists keep their order (first item stays first)
- Lists can contain mixed types
[Analogy: A List is Like a Shopping List]
You write items in order: first eggs, then milk, then bread. You can add items, remove items, or check what's at position 2. Python lists work exactly the same way.
[Think Of]
Shopping List: Items in order. Add, remove, or access by position.
[Code Example: Creating and Printing Lists]
fruits = ["apple", "banana", "cherry"]

--- Section 2: Indexing & Slicing ---
[Explanation: Accessing Items with Index]
Each item in a list has a position called an **index**. Python uses zero-based indexing.
Index starts at 0: fruits[0] is the first item
- Negative index counts from end: fruits[-1] is last
- Slicing extracts a portion: fruits[1:3] gets index 1 and 2
- len(list) gives the number of items
[Code Example: Indexing and Slicing]
fruits = ["apple", "banana", "cherry", "date", "elderberry"]
print(fruits[0])
print(fruits[-1])
print(fruits[1:4])
print(fruits[:3])
print(fruits[2:])
print(fruits[::2])

Lists have built-in **methods** that let you modify and analyze them.
append(item) — adds item to the end

- sort() — sorts in ascending order
- len(list) — returns the number of items

A **tuple** is like a list but **immutable** — you cannot change it after creation. Use parentheses ().

- Swap variables: a, b = b, a (uses tuple unpacking)

--- Section 1: Why Functions? ---
[Explanation: Why Do We Need Functions?]
Without functions, you copy-paste the same code everywhere. Functions let you **define once, use many times**.

- Fix bugs in one place instead of everywhere

- Parameters with defaults must come LAST

TITLE: File Handling

--- Section 1: Why Files? ---
[Explanation: Why Do We Need File Handling?]
Without files, all data disappears when your program ends. Files let you save data permanently.
Variables disappear when the program closes — files persist
- Files let you share data between different programs
- Real applications save user data, settings, and logs to files
- Python handles text files (.txt) and structured files (.csv, .json)
[Analogy: File Handling is Like a Notebook]
Writing in a notebook saves information even after you close it. Open it tomorrow and the information is still there. File handling does the same for your programs.
[Think Of]
Notebook: Open it, read/write pages, close it when done.

--- Section 2: Reading Files ---
[Explanation: Opening and Reading Files]
Use the open() function to work with files. The default mode is 'read' (r).
file = open("filename.txt", "r") — opens for reading
- file.read() — reads the entire file as one string
- file.readlines() — reads all lines into a list
- Always close the file: file.close()
[Code Example: Reading a File]
# First create a file
with open("notes.txt", "w") as f:
    f.write("Line 1\nLine 2\nLine 3")

# Now read it
with open("notes.txt", "r") as file:
    content = file.read()
    print(content)
[Explanation: The with Statement]
The `with` statement automatically closes the file even if an error occurs.
with open("file.txt", "r") as f: — auto-closes when done
- No need to call .close() manually
- Safer and cleaner than manual open/close

--- Section 3: Writing Files ---
[Explanation: Writing and Appending]
Python has three main file modes: read (r), write (w), and append (a).
"w" mode — WRITE: creates or overwrites
- "a" mode — APPEND: adds to end of existing file
- "r" mode — READ: reads from existing file
- Use "w" carefully — it deletes existing content!
[Code Example: Write vs Append]
with open("diary.txt", "w") as f:
    f.write("Day 1: Started Python\n")

with open("diary.txt", "a") as f:
    f.write("Day 2: File handling!\n")

with open("diary.txt", "r") as f:
    print(f.read())
