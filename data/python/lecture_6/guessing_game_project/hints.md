# Hints

1. Use a dictionary or `if`/`elif` to map difficulty choices to (max_number, max_guesses) pairs.
2. Use `random.randint(1, max_num)` to generate the secret number.
3. Use a `for` loop over `range(max_guesses)` to limit attempts.
4. Use `int(input(...))` to read and convert each guess.
5. Use `if`/`elif` to check if the guess is correct, too high, or too low.
