# Hints

1. Define all 8 conversion functions at the top of your program, each with `def` and a `return` statement.
2. Each function should do one thing: take a number, apply a formula, return the result.
3. Use `float(input(...))` to read numeric values from the user.
4. Use f-string formatting `{value:.1f}` to display one decimal place.
5. Structure the main loop with sub-menus for each category, or use a single menu with 8 options.
