# Testing

Test each operation:

1. **Add:** Add "Alice", "Bob", "Charlie" with different phone numbers.
2. **View:** Verify all three appear in alphabetical order (Alice, Bob, Charlie).
3. **Search:** Search for "Bob" — verify details display. Search for "Zoe" — verify "not found".
4. **Update:** Update Alice's phone number — verify by viewing or searching.
5. **Delete:** Delete Bob — verify he no longer appears in the list.
6. **Case insensitivity:** Search for "alice" (lowercase) — verify Alice still found.
