# Understanding

Dictionaries are one of Python's most versatile data structures. They store key-value pairs, enabling fast lookups by name — just like a real contact book. This project also introduces **nested dictionaries** (a dictionary where each value is itself a dictionary), **case-insensitive lookup** (normalizing keys to lowercase), and the **CRUD pattern** (Create, Read, Update, Delete) that appears in nearly every database-backed application.
