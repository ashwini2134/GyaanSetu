# Contact Book

Write a Python program that manages a contact book using dictionaries. Each contact has a name, phone number, and email address.

**Example interaction:**
```
--- Contact Book ---
1. Add contact
2. View all contacts
3. Search by name
4. Update phone
5. Delete contact
6. Exit
Enter choice: 1
Enter name: Alice
Enter phone: 555-1234
Enter email: alice@example.com
Contact "Alice" added.

--- Contact Book ---
1. Add contact
2. View all contacts
3. Search by name
4. Update phone
5. Delete contact
6. Exit
Enter choice: 3
Enter name to search: Alice
Name: Alice
Phone: 555-1234
Email: alice@example.com
```
