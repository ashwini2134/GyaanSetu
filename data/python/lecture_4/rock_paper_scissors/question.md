# Rock, Paper, Scissors

Write a Python program that lets the user play Rock, Paper, Scissors against the computer. The game should:

1. Ask the user to choose rock, paper, or scissors.
2. Have the computer make a random choice.
3. Determine the winner based on standard rules.
4. Keep score and ask if the user wants to play again.

**Example interaction:**
```
Welcome to Rock, Paper, Scissors!
Enter rock, paper, or scissors: rock
Computer chose: paper
You lose!
Score — You: 0, Computer: 1
Play again? (y/n): y

Enter rock, paper, or scissors: scissors
Computer chose: paper
You win!
Score — You: 1, Computer: 1
Play again? (y/n): n
Final score — You: 1, Computer: 1
Goodbye!
```
