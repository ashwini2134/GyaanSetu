# Personal Diary — Journal App

Write a Python program that lets the user write and manage personal diary entries. Entries are saved to a file so they persist between program runs.

**Example interaction:**
```
--- Personal Diary ---
1. Write a new entry
2. View all entries
3. Search entries by date
4. Search entries by keyword
5. Delete an entry
6. Exit
Enter choice: 1

--- New Entry ---
Date: 2026-06-12
Title: My first day of Python
Content: Today I learned about variables and data types.
I wrote my first program!
Entry saved.

--- Personal Diary ---
1. Write a new entry
2. View all entries
3. Search entries by date
4. Search entries by keyword
5. Delete an entry
6. Exit
Enter choice: 2

--- All Entries ---
[2026-06-12] My first day of Python
Today I learned about variables and data types.
I wrote my first program!
---
```
