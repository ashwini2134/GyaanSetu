# Shopping List Manager

Write a Python program that lets the user manage a shopping list through a text-based menu. The user can add items, remove items, view the list, mark items as purchased, and clear purchased items.

**Example interaction:**
```
--- Shopping List Manager ---
1. Add item
2. Remove item
3. View list
4. Mark as purchased
5. Clear purchased items
6. Exit
Enter choice: 1
Enter item name: apples
"apples" added to the list.

--- Shopping List Manager ---
1. Add item
2. Remove item
3. View list
4. Mark as purchased
5. Clear purchased items
6. Exit
Enter choice: 3
Your shopping list:
1. [ ] apples
```
