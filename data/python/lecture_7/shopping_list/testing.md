# Testing

Test each menu option:

1. **Add:** Add "apples", "bread", "milk" — verify they appear in the list.
2. **View:** Check all three items appear with `[ ]` status.
3. **Mark as purchased:** Mark "apples" — verify it shows `[x]`.
4. **Clear purchased:** Clear — verify "apples" is gone but "bread" and "milk" remain.
5. **Remove:** Remove "bread" — verify only "milk" remains.
6. **Exit:** Verify the program exits gracefully.
