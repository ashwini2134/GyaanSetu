# Hints

1. Use a nested dictionary structure: `students[name][subject] = grade`.
2. Write helper functions for each menu option to keep the main loop clean.
3. For file save/load, use a simple pipe-delimited format: `name|subject|grade`.
4. Use `try`/`except` to validate that grades are valid numbers.
5. The `letter_grade()` function should take a numeric average and return A/B/C/D/F using `if`/`elif`.
