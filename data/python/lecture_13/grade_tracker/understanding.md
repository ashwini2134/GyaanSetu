# Understanding

The Student Grade Tracker is the capstone project because it brings together every major concept from the course: **dictionaries** (nested for students → subjects → grades), **functions** (modularizing each operation), **file I/O** (save/load with persistence), **loops** (menu loop, iterating over data), **conditionals** (letter grade thresholds, input validation), and **exception handling** (grade number validation). Working on a larger program like this trains you to think about **program architecture** — how to organize code so it's readable, maintainable, and extensible.
