# Hints

1. Use `input()` to get the size and `int()` to convert it.
2. Use `.isdigit()` or a `try`/`except` to validate the input is a positive number.
3. The outer loop runs from 1 to `n` for rows; the inner loop runs from 1 to `n` for columns.
4. Use `end=""` in `print()` to keep output on the same line.
5. Use f-string width specifiers like `f"{value:4}"` to align columns evenly.
