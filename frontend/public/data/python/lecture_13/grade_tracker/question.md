# Student Grade Tracker

Write a complete Python program that manages student grades. This capstone project combines everything you've learned: dictionaries, lists, functions, file I/O, loops, and conditionals.

**Example interaction:**
```
--- Student Grade Tracker ---
1. Add student
2. Add grade
3. View all students
4. View student report
5. Class average
6. Save & Exit
Enter choice: 1
Enter student name: Alice

--- Student Grade Tracker ---
1. Add student
2. Add grade
3. View all students
4. View student report
5. Class average
6. Save & Exit
Enter choice: 2
Enter student name: Alice
Enter subject: Math
Enter grade: 85
Grade added.
```
