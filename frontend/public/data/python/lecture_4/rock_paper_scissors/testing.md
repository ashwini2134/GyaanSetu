# Testing

Run your program and test these scenarios:

1. Enter "rock", "paper", and "scissors" — verify correct winner each time.
2. Enter "Rock" (capitalized) — verify case-insensitive handling.
3. Enter an invalid option like "banana" — verify it asks again.
4. Play at least 3 rounds, then type "n" to quit — verify final score is correct.
5. Verify the computer's choice changes each round (not always the same).
