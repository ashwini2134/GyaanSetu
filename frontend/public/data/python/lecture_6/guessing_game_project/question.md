# Number Guessing Game with Difficulty Levels

Write a Python program that picks a random number and lets the user guess it. Support three difficulty levels that affect the range and number of allowed guesses.

**Example interaction:**
```
Welcome to the Number Guessing Game!
Select difficulty:
1. Easy (1-50, 10 guesses)
2. Medium (1-100, 7 guesses)
3. Hard (1-200, 5 guesses)
Enter choice (1/2/3): 2

I'm thinking of a number between 1 and 100.
You have 7 guesses.

Guess 1: 50
Too high!
Guess 2: 25
Too low!
Guess 3: 37
Too low!
Guess 4: 42
Correct! You got it in 4 guesses!
```
