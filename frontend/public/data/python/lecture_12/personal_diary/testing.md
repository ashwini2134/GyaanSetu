# Testing

Test each feature:

1. **Write:** Add 2-3 entries with different dates and titles.
2. **View:** Verify all entries display with date, title, and content.
3. **Search by date:** Search for a date that exists and one that doesn't.
4. **Search by keyword:** Search for a word in a title and a word in content.
5. **Delete:** Delete an entry, then view — verify it's gone.
6. **Persistence:** Exit the program and run it again — verify entries are still there.
