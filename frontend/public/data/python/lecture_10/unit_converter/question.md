# Unit Converter Toolkit

Write a Python program that converts between different units. The program should use functions to organize each type of conversion.

**Example interaction:**
```
--- Unit Converter Toolkit ---
1. Temperature (Celsius ↔ Fahrenheit)
2. Length (km ↔ miles)
3. Weight (kg ↔ pounds)
4. Time (hours ↔ minutes)
5. Exit
Enter choice: 1

--- Temperature Converter ---
1. Celsius to Fahrenheit
2. Fahrenheit to Celsius
Enter choice: 1
Enter temperature in Celsius: 100
100°C = 212.0°F
```
