# Testing

Test each conversion category:

1. **Temperature:** 100°C → 212°F, 32°F → 0°C.
2. **Length:** 10 km → 6.2 miles, 10 miles → 16.1 km.
3. **Weight:** 5 kg → 11.0 lbs, 10 lbs → 4.5 kg.
4. **Time:** 2 hours → 120 minutes, 90 minutes → 1.5 hours.
5. Verify decimal precision (one decimal place).
6. Test that invalid menu choices are handled.
