# Hints

1. Start by getting all four inputs at the top of your program.
2. Store each input in a separate variable with a clear name.
3. Use f-strings like `f"Hello, {name}!"` to insert variables into your story.
4. Use `print()` with an empty string `print()` to add blank lines between sections.
5. Test your program by running it and typing different answers to see how the story changes.
