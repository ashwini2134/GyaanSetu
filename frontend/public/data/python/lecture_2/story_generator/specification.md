# Specification

## Requirements

Your program must:

1. Prompt the user for their **name** using `input()`.
2. Prompt the user for their **age** using `input()`.
3. Prompt the user for their **favorite color** using `input()`.
4. Prompt the user for their **hobby** using `input()`.
5. Print a story that is at least **4 lines long** and incorporates all four inputs.
6. Use **f-strings** to embed the variables in the story text.

## Constraints

- Use only Python built-ins — no external libraries.
- The story must use the user's actual inputs (not hardcoded text).
- Output should be neatly formatted with clear line breaks.

## Example

```
Enter your name: Alex
Enter your age: 25
Enter your favorite color: green
Enter your hobby: coding

--- Your Story ---
Meet Alex, a 25-year-old who sees the world through green-tinted glasses.
When Alex isn't busy being 25, you'll find them coding.
Their friends say Alex's favorite color, green, perfectly matches their personality.
If you ask Alex, there's no better way to spend a day than coding!
```
