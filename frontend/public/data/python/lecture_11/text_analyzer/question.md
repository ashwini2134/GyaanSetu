# Text Analyzer

Write a Python program that analyzes a paragraph of text and reports useful statistics about it.

**Example interaction:**
```
--- Text Analyzer ---
Enter a paragraph (or type 'done' on a line by itself to finish):
This is a sample paragraph. It has multiple sentences!
It also has multiple lines. done

--- Analysis Results ---
Original text: 117 characters (96 without spaces)
Word count: 20
Average word length: 4.8 characters
Number of sentences: 4
Unique words: 16
Most common word: "a" (appears 2 times)
```
