# Loops

## 1. for Loop
Used when the number of iterations is known.
```java
for (int i = 0; i < 5; i++) { ... }
```

## 2. while Loop
Loops through a block of code as long as a specified condition is true.
```java
while (x < 10) { ... }
```

## 3. do-while Loop
Executes the code block once, before checking if the condition is true.
```java
do { ... } while (x < 10);
```
