# Conditionals

## 1. if-else Statements
Execute code if a condition is true, otherwise execute another block.
```java
if (x > 10) { ... } else { ... }
```

## 2. switch Statement
Select one of many code blocks to be executed.
```java
switch(day) {
  case 1: print("Monday"); break;
}
```

## 3. Ternary Operator
Shorthand for if-else.
```java
int max = (a > b) ? a : b;
```
