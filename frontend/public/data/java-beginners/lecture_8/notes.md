# Collections

## 1. Set Interface
A collection that contains no duplicate elements (e.g., HashSet).
```java
Set<Integer> uniqueNums = new HashSet<>();
```

## 2. Map Interface
An object that maps keys to values (e.g., HashMap). Keys must be unique.
```java
Map<String, String> capitals = new HashMap<>();
capitals.put("England", "London");
```

## 3. Sorting Collections
Use Collections.sort() for Lists.
```java
Collections.sort(myList);
```
