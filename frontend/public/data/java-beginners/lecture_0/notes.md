# Introduction to Java & JShell

## 1. What is Java?
Java is a high-level, class-based, object-oriented programming language that is designed to have as few implementation dependencies as possible.

## 2. Using JShell
JShell is an interactive Java Shell tool, it allows us to execute Java code snippets and get immediate results.

```java
jshell> System.out.println("Hello World");
Hello World
```

## 3. Variables
You can declare variables easily:
```java
int age = 25;
String name = "Java";
```
